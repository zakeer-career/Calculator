# Changelog

All notable changes to the Calculator project are documented in this file.

## [v1.0] - 2026-09-12
### Added
- Comprehensive Scientific Calculator with real-time expression evaluation.
- High-precision currency converter with support for global currencies and offline fallback rates.
- Unit converter for length, area, volume, mass, temperature, speed, time, and data storage.
- Interactive Matrix operations (addition, subtraction, multiplication, inverse, determinant, transpose).
- Equation solver (linear and quadratic systems).
- Room database persistence for history, favorites, and trash management.
- Modern Jetpack Compose UI with adaptive layouts and multiple theme styles.
- Secure PIN protection with salted SHA-256 hashing and rate-limiting lockout.
